# Machine Learning Network Intrusion Detection System

When I joined the course, I asked myself, "how can I use machine learning in order to help my organization?". Being in cyber for 2 years so far, I face issues with staff shortage and that is one thing that is stopping me in making a complete security operations center. I came to an idea to make a machine learning model that will help us detect malicious traffic in our network, which will hopefully one day be developed into a tool that we can use on daily basis and therefore reduce our need for additional staff. 

In order to make this happen I have looked everywhere for the appropriate dataset that would find its proper use in this project. I found synthetic dataset generated by University of New South Wales from 2015. Even though it's outdated it will help me understand the methodology which I will use later on to develop something better with real and new data.

The intent is to make this model using LogisticRegression() and then, later on, using other algorithms which we haven't covered in class, but I intend on learning on my own and developing for future reference.
